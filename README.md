# Neon Rhythm 🎸

Gra rytmiczna w stylu Guitar Hero w przeglądarce — neonowa, z muzyką i generatorem poziomów.

**Zagraj:** https://tokarskikornel.github.io/my-rythm-game/

## Jak grać

- Nutki spadają w czterech ścieżkach — wciśnij **D F J K**, gdy dotkną linii.
- **PERFECT** (do 50 ms), **GOOD** (do 100 ms), **MISS** — combo podbija mnożnik do x4.
- **Esc** — pauza.
- **🎵 Wczytaj piosenkę z komputera** — gra sama zrobi poziom do twojej muzyki.
  Plik zostaje na twoim komputerze, nigdzie nie jest wysyłany.
